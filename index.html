Before you start

Two chains, two contract languages

Cardano is the public UTxO chain. Contracts are usually written in Aiken and compile to Plutus V3. Midnight is the privacy partner chain. Contracts are written in Compact and every call produces a zero-knowledge proof.

On Windows, Midnight work happens in WSL

The Compact compiler has no Windows build. On Windows, typing compact runs the built-in NTFS compression tool, and it exits with success, so a build looks fine when nothing was built.

Skills help but are not proof

Midnight changes fast and AI knowledge of Compact goes stale. Compile and run anything Claude writes, and use /midnight-verify:verify before trusting a claim.

Setup guide: Claude Code + VS Code

Written for a Windows machine. On macOS or Linux, skip step 1 and run everything in your normal terminal.

  1. Install WSL, VS Code and Docker on Windows

    In PowerShell (run as administrator), install Ubuntu under WSL2, then reboot:

    wsl --install -d Ubuntu
    • Install VS Code and Docker Desktop. In Docker Desktop, go to Settings › Resources › WSL integration and turn on Ubuntu.
    • Install Chrome for the wallet extensions.
    • Reference: Microsoft WSL install guide.

  2. Add the VS Code extensions

    • Claude Code
    • WSL, which opens folders inside Ubuntu
    • Aiken for Aiken syntax and diagnostics
    • Compact Language Support. It is not on the Marketplace. Get the VSIX from the Midnight install page, then use Extensions › ⋯ › Install from VSIX.

    Always open projects from the Ubuntu terminal so VS Code connects to WSL. When VS Code asks, install the extensions "in WSL" too.

    mkdir -p ~/code && cd ~/code
code .

    Docs: Claude Code in VS Code. The extension and the claude CLI share the same plugins, skills and MCP config.

  3. Install Node 22 and the Claude Code CLI inside WSL

    Install nvm using the install line from its README, then:

    nvm install 22
corepack enable          # gives you Yarn 4 for the official examples
curl -fsSL https://claude.ai/install.sh | bash
claude --version

    Install guide: code.claude.com/docs/en/setup.

  4. Install the Compact toolchain (Midnight)

    curl --proto '=https' --tlsv1.2 -LsSf https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh
# restart the terminal, then pin the compiler version from the support matrix
compact update 0.31.1
compact compile --version

    As of 25 Oct 2026, 0.31.1 is both the version in the docs example and the one the official examples pin. Check the support matrix first. A bare compact update takes the newest release, which can be ahead of the public networks.

    compact compile +<version> only selects a version you already have. Run compact update <version> first, or the build fails on a clean machine.

  5. Run a local proof server (Docker)

    docker run -p 6300:6300 midnightntwrk/proof-server:8.1.3
    • The tag is the one the docs list today. Match it to the support matrix.
    • In the Lace wallet, go to Settings › Midnight and choose Local (http://localhost:6300).
    • The create-mn-app and midnight-examples projects start their own proof server with Docker Compose. You only need this one for wallets and the public networks.

  6. Install Aiken (Cardano)

    curl --proto '=https' --tlsv1.2 -LsSf https://install.aiken-lang.org | sh
aikup                    # installs the latest Aiken
aiken --version

    Aiken also runs natively on Windows: powershell -c "irm https://windows.aiken-lang.org | iex". See the install guide.

  7. Install the Claude Code plugins and skills

    Midnight (official marketplace, maintained in the midnightntwrk org):

    claude plugin marketplace add https://midnightntwrk.expert
claude plugin install --scope user midnight-expert@midnight-expert
claude plugin install --scope user compact-core@midnight-expert
claude plugin install --scope user compact-examples@midnight-expert
claude plugin install --scope user midnight-dapp-dev@midnight-expert
claude plugin install --scope user midnight-verify@midnight-expert
claude plugin install --scope user midnight-tooling@midnight-expert
claude plugin install --scope user midnight-wallet@midnight-expert

    Restart Claude Code, then run /midnight-expert:doctor to check the environment.

    Edda Labs Midnight plugin:

    claude plugin marketplace add eddalabs/edda-marketplace
claude plugin install --scope user midnight@edda-labs-marketplace

    Cardano:

    npx skills add Flux-Point-Studios/cardano-agent-skills
claude plugin marketplace add cardano-foundation/cardano-dev-skills
claude plugin install --scope user cardano-dev-skills@cardano-dev-skills

    Before installing the full cardano-dev-skills plugin, read the watch-outs. It ships thousands of third-party doc files.

    Keep things current with claude plugin marketplace update <name> and then claude plugin update <plugin>@<marketplace>. Docs: plugins, skills.

  8. Add MCP servers

    claude mcp add --scope user midnight -- npx -y midnight-mcp@latest
claude mcp add --scope user octocode -- npx -y octocode-mcp
claude mcp add --scope user nightgate --env ODATANO_ACCESS_KEY=oda_... -- npx -y @odatano/nightgate-mcp
claude mcp list
    • The ODATANO servers need an ODATANO access key. @odatano/core-mcp is the Cardano one and is added the same way.
    • For agent wallet operations on Cardano, npx @indigoprotocol/cardano-mcp setup sets up the optional provider used by the cardano-mcp-* skills. Use a test wallet only.
    • On native Windows (not WSL), wrap the command as cmd /c npx ….

    Docs: MCP in Claude Code.

  9. Set up wallets and get test funds

    • Midnight: install Lace (Midnight enabled) or the 1AM wallet. Get tNIGHT from the Preprod faucet or the Preview faucet. Fees are paid in DUST, which accrues from NIGHT you hold.
    • Midnight endpoints: Preview has public Midnight-hosted endpoints. Preprod and Mainnet RPC go through Blockfrost and need a token from a "Midnight Preprod" (or Mainnet) project on blockfrost.io.
    • Cardano: set Lace or Eternl to Preprod, get test ADA from the testnet faucet, and create a free Cardano Preprod project key on Blockfrost, or use Koios.

    A brand-new wallet on Midnight Preprod takes about 78 minutes to sync to the chain tip, according to the official examples README. Start on the local devnet.

  10. Build something

    Midnight: scaffold, then follow the official learning path. Run this in WSL:

    npx create-mn-app@latest my-app
cd my-app
npm run setup            # local devnet + compile + deploy; no wallet or faucet needed

    Next, work through midnight-examples in order: hello-world, private-bid, battleship, private-tip-jar, shielded-chips, then zk-loan.

    Cardano: an Aiken validator, plus MeshJS for off-chain transaction building:

    aiken new my-org/hello
cd hello
aiken check && aiken build   # writes plutus.json, the contract blueprint
npm install @meshsdk/core

    Try these in Claude Code: /midnight-dapp-dev:init, /compact-cli-dev:init, /midnight-tooling:devnet, /compact-core:review-compact, /compact-core:audit-compact, and the cf-review-contract skill for Aiken validators.

Watch-outs

  • Old tutorials point at archived repos.example-counter and midnight-local-dev are archived. Use create-mn-app and midnight-examples instead. Today the official examples pin Compact language 0.23, compiler 0.31.1, and midnight-js 4.1.1.
  • A successful compact run on Windows proves nothing.It's the NTFS tool, and it exits 0. Run which compact inside WSL to confirm you're using the real one.
  • Pin compiler versions explicitly.Run compact update <v> before compact compile +<v>, and match the support matrix, not the newest release.
  • The cardano-dev-skills plugin bundles a lot of third-party documentation.Its own supply-chain notes list prompt injection through those docs as a risk. You can copy only the skills you need.
  • The MIDSKILLS installer reports your GitHub identity to its analytics.Read the skill files on GitHub instead.
  • Community projects in the catalog are listed, not audited.Read the code before you run it, check when it was last updated, and never enter a real seed phrase into a demo.
  • MCP servers and operator skills that can sign must only use test wallets.Never give an agent a key that holds real funds.
